# Equilíbrio
Saúde, tecnologia e bem-estar.

## Sobre
Plataforma interativa para a EXPOTEC 2026 — Curso Técnico em Informática.

## Funcionalidades
- Perfil com foto
- Dashboard com gráficos
- Hidratação, Sono, Movimento, Foco (Pomodoro)
- Ergonomia interativa
- Pausa guiada (respiração)
- Biblioteca educativa
- Check-in de bem-estar
- Quiz de conhecimentos
- Assistente EQUI
- XP, níveis e conquistas
- Acessibilidade e tema escuro

## Tecnologias
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Recharts
- Zustand
- Lucide Icons

## Deploy
Este projeto está pronto para deploy na [Vercel](https://vercel.com).
